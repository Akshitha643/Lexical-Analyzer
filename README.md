# Lexical Analyzer in C

## Description

This project implements a simple Lexical Analyzer using the C programming language. The lexical analyzer reads a C source file, breaks it into tokens, and classifies each token into different categories such as Data Type Keywords, Non-Data Type Keywords, Identifiers, Operators, Integer Literals, Float Literals, and Special Characters.

## Features

* Identifies Data Type Keywords
* Identifies Non-Data Type Keywords
* Detects Identifiers
* Detects Operators
* Detects Integer Literals
* Detects Float Literals
* Detects Special Characters
* Reads input from a C source file

## Files

* `main.c` – Tokenization and file handling
* `lexer.c` – Token classification functions
* `lexer.h` – Function declarations
* `text.c` – Sample input file

## Technologies Used

* C Programming
* GCC Compiler
* Linux / Ubuntu

## Learning Outcome

This project demonstrates the lexical analysis phase of compiler design and helps understand tokenization, file handling, string processing, and modular programming in C.
